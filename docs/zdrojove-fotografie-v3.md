# Fotografie použité ve verzi V2 – výměna fotografií

Obrázky jsou přímo načítány z veřejných adres obrázkového serveru, který používá původní web https://www.alumipergoly.cz/. V důsledku toho je k zobrazení fotografií potřebné aktivní připojení k internetu. HTML, CSS, JavaScript, navigace a rozvržení zůstaly stejné; změnily se pouze URL obrazových podkladů.

Ne všechny podklady na aktuálním firemním webu jsou doložené fotografie skutečných realizací: některé mají názvy naznačující generované vizualizace nebo AdobeStock. Neprezentujte je jako autentické realizace bez potvrzení od firmy. Práva na užití na redesignu musí schválit vlastník či držitel licence, zejména před veřejným publikováním. Pro ostrý web doporučeno stáhnout licencované originály a hostovat je na vlastním serveru.
